Hosting — put server.js next to index.html and run node server.js. It prints a http://… address for everyone on your network and a host:port to paste in the box above.

If you loaded this page from GitHub Pages it is served over https, and a browser will not let an https page talk to a plain socket on a home network. Two ways round it: open the http://… address the server printed instead of the GitHub one — that copy can connect to anything — or host over https behind a tunnel. Connecting to localhost works from either page.
